工程实践归纳

总体判断：固定来源当日没有 Langfuse、LangChain/LangGraph、Code Graph 或 Spring Alibaba AI 的可核验新文；有信号的方向是 RAG 引用要能回到原文位置，以及 Agent 评测与控制必须落到程序和接口上，而不是只看模型自述。

主题 进展 工程启发
RAG 引用 百炼 ParseX 方案把「来源文档」推进到「这一页的这一段」，并用匹配失败时不画框来避免错标。 引用产品的验收标准应是「点得开、框得对、没有就明确说未定位」，而不是只在答案末尾列文档名。
Agent 评测 PawBench 解读表明同一模型换 Hermes / OpenClaw / QwenPaw 分差可接近一次模型升级。 选型评测至少做两因子：固定外壳换模型，或固定模型换外壳；完成判定要查产物，不要只信模型说「做完了」。
多智能体协调 《Worse Together》解读说明，共享资源上「每人一个智能体」可能更差，有些问题只能靠接口拦住。 多用户 Agent 要单独测试越权取消、备注是否在提交前重读、以及是否编造他人意图；只看集体成功率会漏掉对单人的伤害。
Agent 基础设施 腾讯云社区梳理的 Agent CBS 把沙箱磁盘的创建、克隆、隔离和休眠做成专门产品能力。 高并发评测和有状态会话对存储时延、克隆和数据残留的要求，已经和普通云盘不是同一类问题；引用其中指标时需回对官方材料。
Loop / Harness 掘金教程把缰绳写成程序：权限分级、路径沙箱、熔断，并强调步骤固定的事更适合工作流。 与 Loop Engineering 的 maker/checker 分离一致：模型只负责提议，程序决定是否执行；提示词不能替代这些保证。
