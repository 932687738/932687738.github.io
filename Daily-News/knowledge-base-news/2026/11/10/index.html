开源模型 / 长程智能体 美团 LongCat-2.5 正式开源：从看见，到抵达 2026-11-10 美团技术团队 MIT 协议开源，可商用推理与二次训练。模型总参数 1.6 万亿，每 token 激活约 480 亿，支持 100 万上下文，定位长程智能体、复杂代码库/完整项目、Visual Coding 与专业办公。训练上用更多长程与失败轨迹、partial rollout 异步 RL、按通过率动态过采样，并对跨 checkpoint 旧轨迹做梯度校正；环境断网、清 git 历史与文件缓存，再用 LLM judge 约束重复思考和过度工具调用。视觉侧把原生分辨率特征做成多层级离散 token，与文本共享主干，而不是外挂视觉模块。推理采用专家权重与激活均为 4 bit 的 W4A4，并走原生 INT4 矩阵乘；官方称已评测下游任务与量化前相当。国产算力方面，在单卡显存不足 80GB 的条件下用 FSDP 双重分片、拓扑感知并行和通信重叠做长序列训练/微调，长序列 SFT 单卡吞吐量较 DDP 基线提升 86%。模型：meituan-longcat/LongCat-2.5
浏览器执行 WorkBuddy操作浏览器Browser Use，的确很香！ 2026-11-10 掘金 社区实测腾讯 WorkBuddy 的 browser use：装 Chrome/Edge/QQ 浏览器扩展并打开“允许控制浏览器”后，可用 /workbuddy-browser-use 技能在已登录的真实浏览器里点选、滚动和汇总。作者对比了它与 Playwright/Selenium：登录态和页面改版更省事，但路径不稳定、没有断言、单次要几分钟，因此建议一次性/低频/靠人眼看的走查交给它，高频回归仍用脚本。文中还记录它在浏览量统计失效时自行改用“招聘出现频率”口径且不主动说明，提醒验收时要连依据一起核对。这是掘金实践文，不是腾讯官方技术博客原文
GUI / OS Agent 给企业配一双 AI 的手：火山引擎 OS Agent 替你操作手机和电脑 2026-11-10 掘金（火山引擎Agent社区） 火山引擎社区介绍 OS Agent：用自然语言下达目标后，在云端桌面沙箱（CUA）或云手机（MUA）里看懂屏幕、规划、执行并检查结果，必要时请求人工接管。文中给出一条可核验的工程数字：统一 Grounding 后移动端典型任务成功率从约 68% 提到约 81%，规范工具输出后再加 4.3 个百分点；到 2026 年 10 月，线上有效任务成功率稳定在约 95%（移动端）和 97%（桌面端）。确定动作不再走主模型后，典型 A/B 里平均远端耗时从 93.6 秒降到 64.9 秒（约 -29%），Runtime Token 约降 20%。明确不擅长验证码/登录审批、单任务超过 20–30 步，以及“必须一次做对”的高正确性动作

主题 进展 工程启发
