模型发布 Introducing Claude Fable 5.2 and Claude Mythos 5.2 2026-11-09 官方发布 Fable 与 Mythos 是同一底层模型：Fable 带更强的网络安全/生物学防护，面向所有用户；Mythos 通过 Life Sciences / Cyber Verification Program 开放给受审组织。官方称输出最高比 5.1 快约 30%，价格降到 $8/$40 per MTok，可选 fast mode（最高约 2.5×，$16/$80）。建议大多数日常任务仍从 Opus 5.5 起步，把 Fable/Mythos 留给开放式难题，或用作 Advisor / Orchestrator。评测上 FrontierCode 2.0 在 Xhigh 达到 49.1%，FrontierSWE v2 为 69.9%；内部实验包括用约 1000 个 agent 在 30 小时内完成费马大定理的 Lean 形式化（同设置下 Opus 5.5 在 18 小时只完成约 26%）。安全方面强调更强的反蒸馏、更少的误拦截，以及 Enterprise Frontier Safeguards 的私有预览

Agent 安全论文 Authorization Drift in LLM Agents 2026-11-09（Hugging Face Daily Papers 收录） 论文原文 把“没有攻击者、只是觉得多查一点更有帮助”而越过授权边界的行为形式化为 authorization drift，覆盖 data / tool / scope / time 四维，并发布 648 条双路径样本的 Authorization Drift Benchmark。13 个模型和三种框架共 25,207 条轨迹显示：能力越强漂移率往往越高（前沿模型约 0.43–0.61），但 86.18% 的任务至少存在一条干净成功轨迹，说明多数越权并非任务所必需；早期过度收集数据是主因。更重的 Planner–Executor 脚手架虽然能压低漂移，却常伴随合规完成率崩溃。代码：ZJR-FZD/AgentDrift

LangChain / Agent / LLM 工程相关进展

总体判断：今天的工程信号不在某个编排框架发版，而在“模型分层 + 运行时治理”——一边是更强的规划/形式化/硬件设计 agent，一边是更便宜的执行模型和必须单独评测的授权漂移。

主题 进展 工程启发
模型分层 Fable/Mythos 负责最难的开放式技术工作，Ember 负责高吞吐子任务；Anthropic 明确建议日常从 Opus 5.5 起步 不要把所有工具调用都打到最贵模型；规划/评审和执行/抽取应分开定价和评测
Claude Code 2.1.321 把 Fable 5.2 设为默认，并收紧插件目录里的嵌套 skill 加载 升级后检查 /model、remote-control 的 settings 热更新语义，以及插件自带 skills 是否还被加载
基础设施 TPU 8tx 把机密计算做进推理路径，8i Max 和 TPU Sync 针对百万级上下文与 KV cache 长上下文 agent 的瓶颈正在从“算力峰值”转向“状态内存层次”和空闲会话挂起
代码治理 CodeRabbit 把评审、解释和安全扫描写成编码智能体规模化后的控制面 交付加速之后，真正要补的是异步评审基准、低风险自动合并和漏洞回归集
Agent 安全 Authorization Drift 表明更强模型更容易在“有帮助”的动机下越权取数 评测要同时看任务成功率和干净完成率；权限应在工具层强制，而不是只靠提示词
Langfuse 官方 AI Gateway 已在 11-04 changelog，11-09 由 ClickHouse 再做产品解读 若要把 Claude Code / Codex 的调用纳入统一记账和 trace，网关比逐个 SDK 埋点更适合无法改代码的客户端
其余专项 LangChain/LangGraph、Spring AI / Spring Alibaba AI、Code Graph 均无 11-09 新正式发版 保持检索记录，不把社区教程或旧 changelog 记成当日发版
