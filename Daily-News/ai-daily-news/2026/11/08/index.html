主题 标题 日期 类型 研发/学习价值
Agent 进化搜索 SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization 2026-11-08（Hugging Face Daily Papers 收录） 论文原文 每轮 10 个 swarm、各 45 个低成本 agent（共 450）在潜空间推理 40 步，不解码文本，而用 KV cache 通信；novelty filter 按 hidden state 距离每群保留 30 个最不相似的轨迹，summarizer 读取拼接后的 KV cache 写出新程序。21 道数学发现与科学计算题上平均分高于 OpenEvolve / ShinkaEvolve / CodeEvolve；中位数约 3–8 分钟达到基线框架 60 分钟的成绩，吞吐约为 5–13 倍。Qwen3 8B 在若干题上改进了 AlphaEvolve 用前沿模型得到的构造。代码：Qile-J/SwarmEvolve
MoE 可解释性 SAE Interprets MoE 2026-11-08（Hugging Face Daily Papers 收录；arXiv 提交 2026-11-05，标注相邻日期传播） 论文原文 在 Qwen3-30B-A3B 的第 4/30/46 层 MoE 输出上训练 SAE：因为层输出是 router 加权的 expert 之和且 SAE encoder 是仿射的，每个 latent 的预激活可以对 expert 精确分解。贡献比 gating 更集中，多数 latent 只有 1–2 个主导 expert；自动解释显示分工细于粗领域标签（如 Java vs 前端代码、几何 vs 算术/多项式）。代码：ByteDance-Seed/SAE-interprets-MoE
RAG 安全 Signed but Steerable 2026-11-08（Hugging Face Daily Papers 收录） 论文原文 离线 RAG 的签名知识包能证明「谁发布了包」，不能证明「向量编码了对应文本」。若校验器按余弦容忍度接受重算结果，劫持率等于该容忍度下的检索角裕度分布（margin law）。INT8 量级阈值会使 98–100% 查询暴露；在 Raspberry Pi 5 上，攻击把本地模型正确率从约 0.75 降到约 0.39。FAISS PQ 上通过审计的篡改向量能让攻击文档在 25% 目标上排到第一。建议校验量化码并由校验器做 canonicalization。代码：securagenai/signed-but-steerable
端侧 Agent（媒体） 终端侧AI：从单点应用走向智能体体验 2026-11-08（量子位 19:05 Asia/Shanghai） 技术媒体 报道高通在第九届进博会展示端侧 MoE 智能体，合作方包括 Infris AI、江波龙、阶跃星辰。核心工程点是：在端侧内存/功耗约束下用 MoE 提升复杂任务完成度，并通过对将调用 expert 的预测与预取缓解 DDR 带宽瓶颈。属展会演示报道，细节以厂商披露为准
