重要事件与发布

主题 标题 日期 类型 研发/学习价值
科学 Agent / Skills From spectrum to structure: Identifying molecules with Mass Spec Skills for Google Antigravity 2026-11-25 官方发布 用既有质谱工具和公共化学库补上模型算不准的精确质量与碎裂模拟。评测 100 个已建档化合物时，无网络/无技能准确率低于 4%，加上 Mass Spec Skills 后 Gemini 3.8 Flash 与 Gemini 4 Argon/Carbon 都达到约 97%。对未入数据库的新分子，系统只能给出公式与被碎片支持的结构线索，仍需化学家完成鉴定。
生产迁移 / Verifier Migrating our Messages API to Rust 2026-11-25 官方发布 流量约增 1,800 倍后把 Messages API 从 Python 迁到 Rust。测试集约 98% 通过时，生产影子流量一度只有约四分之一输入对齐。做法是只跑一次模型并把输出回放到 Rust、精确对比模型调用前后各阶段，再自动派 agent 修差异。最终在不停机、不冻结功能开发的前提下，每请求 CPU 约降 70%，中位首 token 时延约降 20%。
社会推理评测 Verifiable Social Reasoning for LLM Assistants 2026-11-25 官方发布 用多智能体仿真给隐藏动机提供可核验标签，再让被测助手只通过用户的主观转述做推断。12 个模型上的主要发现是：助手视角明显弱于「旁观完整事件」；容易跟着用户的偏见走；多轮对话不一定更准，因为会锚定先前表述。框架与 2 万余条样本已开源。
AI 编程 Claude Code v2.1.332 2026-11-25 开源发布 MCP 服务器可随工具分发 skills（server:skill）；PreSkillShellCommand 可在 skill 加载时拒绝内联 shell。同时修复命名管道挂起、自动压缩失败、hook/MCP 刷屏导致的冻结，以及 Remote Control 状态误报等生产问题。
Agent 平台 OpenClaw v2026.11.10 2026-11-25 开源发布 Deep Research 默认可在对话中做多源或本地文档调研，并在来源冲突时并排引用、标出未决问题；Knowledge 把会话/会议/文件变成可浏览的本地 Markdown 库（需把 memory 槽位切到 knowledge）；Browser handoff 允许在登录墙或验证码处暂停自动点击、由人接管后继续。同日更早的 2026.11.9 规模较小。

LangChain / Agent / LLM 工程相关进展

总体判断：本日工程信号不在 LangChain 核心库，而在「把核验做成系统」：生产影子对比、领域工具闭环、MCP skills 的加载期拦截，以及 trace 级评测。

主题 进展 工程启发
Loop / Verifier Anthropic 发现测试集高通过率不能代表生产对齐，于是用线上流量当 verifier，并让 agent 自动修差异。 存活系统迁移要先解决「何为正确」；非确定性模型输出必须固定后再比协议层，否则差异无法归因。
领域 Skills Mass Spec Skills 证明轻量模型配上可靠工具后，鉴定准确率可以追平前沿模型；只开放上网写临时脚本则明显更脆。 专业任务优先封装经过验证的工具链，而不是给模型一个浏览器让它现场写分析代码。
MCP / Skills Claude Code 允许 MCP 服务器随工具分发 skills，同时用 hook 在加载阶段否决内联 shell。 技能更新应跟服务器走，但加载时必须有拒绝通道，不能把「会做事」当成「允许执行」。
可观测性 Langfuse v4.86.0 把图表送进 MCP App，并提供 trace 级 transcript 评测。 评测要从单条生成扩展到整段对话/轨迹；图表最好直接出现在 Agent 工作面里，而不是只在独立控制台。
社会推理 Google 的评测表明，助手若只听用户转述，会放大偏见，多轮也不一定纠正。 做咨询/支持类助手时，要允许并鼓励澄清提问，避免把用户的怀疑直接写成结论。
LangChain / LangGraph 核心库在本日 00:00–23:59（Asia/Shanghai）窗口内无新 release；若干集成包发布时间已进入 11-26 凌晨。 不要按 UTC 日历日直接收录 GitHub release；跨时区时以 Published 时刻换算后再写入对应日期。
