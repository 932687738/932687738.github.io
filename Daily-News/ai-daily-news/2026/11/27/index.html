Spring Alibaba AI Spring AI Alibaba v2.1.0.0 2026-11-27（Published 2026-11-27T01:31:10Z，中国时间 09:31） 开源发布 将 Spring AI 2.1.0 与 Spring Boot 4.2.0 接到 ReactAgent、Graph、Studio 以及阿里云集成，并配套 Extensions 2.1.0.0、MCP Java SDK 2.2.0、Nacos 3.3.0。Agent/Graph 侧：ReactAgent 在 advisors 之后按最终请求做 request-scoped 工具分发，默认每工具 40 次、每轮合计 150 次；Graph 支持工具确认与显式 HITL，一批调用可混合批准/编辑/拒绝，恢复时会再检查已注册回调；Message Parts、推理内容和 provider 载荷可在流式聚合、checkpoint 与 Studio DTO 中往返。工作流节点可用 DecisionModel 做 QuestionClassifierNode 路由，LlmNode 可按图状态中的 session ID 接入 Session Memory。Extensions：DashScope HTTP/SDK 适配器保留 Message Parts 与流式工具调用，Qwen / GLM / Kimi 走原生百炼端点；补齐图像/视频/语音与 CosyVoice；DashScopeRagApi / DashScopeRagDocumentRetriever 接入百炼知识库；AnalyticDB、OceanBase、OpenSearch、Tablestore、Tair 支持直接写入/检索预计算向量。升级需同时引入 spring-ai-alibaba-bom:2.1.0.0（及 extensions BOM），并把 Spring Boot 升到 4.2、Spring AI 升到 2.1；启用 Session Memory 时为每段对话使用独立 session ID。
Langfuse Langfuse v4.88.0 2026-11-27（Published 2026-11-26T16:50:41Z，中国时间 11-27 00:50） 开源发布 相对 v4.87.0：组织和实例可关闭公开 trace / session 分享；AI Gateway 增加 redact 护栏动作，未计价用量告警可关联到组织模型，护栏 7 日标记计数可跳转到过滤后的 traces；MCP span 会记录客户端能力与扩展；ClickHouse Cloud 增加 JWT 认证模式；新建的 onboarding API key 会做成具名 Developer key。另有 worker 在关闭时重新入队 blob 导出、避免 OpenRouter Broadcast 递归追踪，以及 MCP 相关稳定性修复。v4.87.0 已计入 11-26，不重记。

LangChain / Agent / LLM 工程相关进展

总体判断：本日工程增量集中在 Java 与可观测控制面，而不是 Python LangChain / LangGraph 的新包版本——阿里把 Spring AI 2.1 的判定、记忆和审批语义接进 Graph，Langfuse 则把分享范围和脱敏做成可管理的护栏。

主题 进展 工程启发
Spring AI Alibaba Graph / ReactAgent 2.1.0.0 让工具分发归属 ReactAgent，并在 Graph 中保留确认、编辑、拒绝与恢复后再校验。 迁移时不要继续把工具审批只挂在 ChatClient advisor 上；限额、确认和 checkpoint 应视为同一控制面。被拒绝或不可用的调用不消耗 per-turn budget，适合把「模型想调用」和「系统允许调用」分开记账。
Session Memory 与 DecisionModel 上游 ChatMemory 已弃用，Alibaba 工作流可用 LlmNode.sessionMemory 与 QuestionClassifierNode.decisionModel。 会话 ID 必须按对话隔离；分类/路由优先走类型化 DecisionModel，而不是再把自然语言回复当成路由协议。
Langfuse 控制面 v4.88.0 让分享成为组织/实例策略，并把 redact 放进 AI Gateway。 生产租户应默认关闭公开分享；脱敏是网关动作，而不是只靠事后改 trace。
LangChain / LangGraph 窗口内无新稳定 release。 继续沿用 11-26 已收录的 langchain-core 1.8.5 与 langgraph-cli 0.4.44，不必为了「赶上今天」升级。
