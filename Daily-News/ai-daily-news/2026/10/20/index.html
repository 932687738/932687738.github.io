重要事件与发布

主题 标题 日期 类型 研发/学习价值
DeepSeek DeepInfer 2026-10-20 开源发布 仓库说明这是支撑大规模生产服务的推理框架，本次只开放离线推理。支持 DeepSeek-V4.1-Flash，硬件写的是 NVIDIA SM100 和华为昇腾 950。完整在线服务仍要自备 KV 缓存、VE/Prefill/Decode 分离和跨 DP 副本的负载均衡。无 GitHub Release
GitHub 包防火墙公开预览 2026-10-20 官方发布 挡在 Actions、编码代理和上游仓库之间，检查元数据请求和包下载。企业可配冷却期、Advisory Database 里的恶意软件或漏洞，以及证明降级。现只支持 npm，GitHub Enterprise Cloud 预览期免费，正式商用后按量计费
OpenAI 收购 Orchestra Bio 2026-10-20 官方发布 把药物研发的项目协调平台并进 Rosalind。官方描述是人和 Agent 一起盯试验与战役：一批生产失败会牵动临床试验，Agent 先标出受影响的活动和时间线。决策仍留给科学家和项目负责人
OpenAI ChatGPT 10 月 20 日更新 2026-10-20 官方发布 锁定对话用 4 位 PIN 或设备认证打开，不出现在普通历史、置顶和搜索里，保留与模型改进设置不变。Slides 面向有 Space 的 Pro、Business、Enterprise。GPT-6 Pro 可让多个 Agent 并行做同一任务的不同部分。GPT-6.1 Sol 开始在 ChatGPT Work 和 Codex 向 Pro 铺开
Anthropic 用 Claude 缩小代码攻击面 2026-10-20 官方发布 在 25 个开源项目里标出 493 个问题。三条路径是默认配置里不该暴露的代码、两个选项叠在一起才出问题、以及认证前或无交互就能走到的敏感代码。做法是把可达性往后推，不是逐个漏洞修补
Anthropic 蝎毒微型结合蛋白 2026-10-20 官方发布 内部研究模型生成 318,484 个设计，选出 180 个，团队再补 31 个。Adaptyv Bio 与 Twist 测了 211 个，17 个达到结合标准。官方写明没有在细胞环境里验证能否中和毒素，不声称做出抗毒血清
推理基础设施 llm-d 1.0 2026-10-20 开源发布 CNCF Sandbox 项目，Kubernetes 上调度 vLLM 与 SGLang。1.0 补的是多租户流控、路由高可用和不停机升级、会话感知路由，以及 Responses API 状态。仓库 v1.0.0 于 02:30Z 发布，北京时间 10:30
Langfuse v4.65.0 2026-10-20（13:35Z，北京时间 21:35） 开源发布 大量 topic 的聚类改为不阻塞；topic 按 facet 在问什么来命名。Skills API 稳住并恢复 MCP。自建 AI gateway 可以选 None 采集，随后的修复让这种模式不再要求采集项目或签名密钥
评测 可监控性的补充指标 2026-10-20 官方发布 配对指标避免不同模型评的不是同一批样本；事后控制指标模拟「监视器否决后再采样」。干预评测里，原来的 g-mean² 被写成上界，文中补了下界
企业落地 Octave 在 Bedrock 上的多租户底座 2026-10-20 技术媒体 质量系统先做隔离底座再做功能。投诉分诊用独立 microVM，附件当不可信输入，Guardrails 打在嵌入前、进上下文前和给人看之前。Cohere Embed v4 在自有语料上把维度收到 512，存储大约少三分之二。文中称单次调查少掉 4–6 小时，每个用例的上线时间少一半。处置决定仍由质检人员做
