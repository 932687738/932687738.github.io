对话的扩展能力有四类：本地工具、技能、插件、外部工具协议。它们都先注册，再由编排计划裁剪之后交给同一次模型调用。

<!-- more -->

本地工具是 Spring Bean 上的公开方法。描述里写清适用场景和反例，调用前先做权限检查，再通过检索端口拿数据：

```java
@Tool(description = """
        名称：平台知识库检索
        适用场景：需要从指定知识库检索 FAQ、产品手册、政策条款等文档片段时使用。
        反例：实时天气、当前时间、代码文件读写、订单状态查询。
        返回：若干 `[来源: 文档名] 内容` 片段；无命中时返回提示语。
        """)
public String searchPlatformKnowledge(
        @ToolParam(description = "用户问题或检索关键词") String query,
        @ToolParam(description = "知识库 ID") Long knowledgeBaseId,
        @ToolParam(description = "租户 ID，可空则 default") String tenantId) {
    return format(searchAsToolResult(query, knowledgeBaseId, tenantId));
}
```

技能是一组「额外系统提示 + 自带工具」。渲染提示词时把技能说明并进去，工具则并入注册表。平台里还有两种技能：一种定义在数据库里，可以发新版本并扫描冲突；一种在启动时编译成图再登记，例如先检索再汇总，或让两个子智能体按顺序做完再合并。图技能的扩展方式是提供图模板和节点，启动时自动编译，而不是在请求里临时拼流程。

插件在启动时注册进系统上下文。可以是普通 Bean，也可以走 `spring.factories` 发现。插件适合接入一组相关能力，不适合在插件里重写路由。

外部工具协议分客户端和服务端。客户端把别处提供的工具变成回调，并入本次调用；服务端可以把本地工具暴露给外部宿主。文件类内置能力会打开这条通道，其他能力默认关闭，避免无关工具进入上下文。

一次调用看到的工具由编排计划的白名单裁剪，再按问句相关性取前五个：

```java
private static final int MAX_TOOLS_PER_LLM = 5;

public SelectedTools selectForPlan(String userInput, OrchestrationPlan plan) {
    List<String> rankedNames = rankToolNames(userInput, plan.allowedToolNames());
    List<String> selectedNames = rankedNames.size() <= MAX_TOOLS_PER_LLM
            ? rankedNames
            : rankedNames.subList(0, MAX_TOOLS_PER_LLM);
    Set<String> selectedSet = Set.copyOf(selectedNames);
    List<Object> locals = toolObjectsForNames(selectedSet);
    ToolCallback[] externals = externalToolCallbacks.stream()
            .filter(callback -> selectedSet.contains(callback.getToolDefinition().name()))
            .limit(MAX_TOOLS_PER_LLM)
            .toArray(ToolCallback[]::new);
    return new SelectedTools(locals, externals);
}
```

聊天服务把本地工具和外部回调分两路挂上同一次调用，并用会话号隔开记忆：

```java
var prompt = chatClientBuilder.clone().build().prompt()
        .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, context.conversationId())
                .advisors(memoryAdvisor))
        .system(systemPrompt)
        .user(userInput)
        .tools(tools.toArray());
if (externalCallbacks.length > 0) {
    prompt = prompt.toolCallbacks(externalCallbacks);
}
```工具的返回按原意写回对话历史，下一步推理读的是这份结果。

钩子不改变路由，只在旁边监听：调用前、调用后（带完整回答）、出错，以及「这段内容值不值得捕获」。审计钩子记会话、智能体、能力和回答规模。是否写入长期知识由单独的捕获判断决定，默认规则可以换成更轻的分类器，但入口仍是这个事件，而不是在聊天服务里加分支。
